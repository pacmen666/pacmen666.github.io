# Cheng Peng · Personal website

Live: **https://pacmen666.github.io/**

A bilingual Chinese/English research and engineering portfolio. Plain HTML, CSS, and JavaScript; no build step, framework, third-party fonts, analytics, or API keys.

## Maintain

- `index.html`: content. Chinese is the default text; `data-en` holds each English translation. Keep both in sync.
- `style.css`: responsive layout and print styles.
- `script.js`: language preference and print action.
- `sitemap.xml`: update `lastmod` when substantive content changes.

Preview with `python3 -m http.server 8765`, then open http://localhost:8765.
GitHub Pages serves the root of `main`.
